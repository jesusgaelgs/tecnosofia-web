📚 Guía: Publica tu página en internet

Sigue estos pasos. No necesitas saber programar.

Descarga la guía completa

PDF con capturas de pantalla paso a paso

📄 Descargar PDF gratuito
  1. Crea cuenta en GitHub: github.com → Sign up → Llena el formulario
  2. Crea un repositorio: En GitHub, clic en "+" → "New repository" → Nombre: mi-pagina
  3. Sube tus archivos: Clic en "uploading an existing file" → Arrastra tu index.html
  4. Crea cuenta en Vercel: vercel.com → Sign up → Continue with GitHub
  5. Importa tu proyecto: En Vercel → Add New → Project → Import tu repositorio → Deploy
  6. Copia tu enlace: Verás algo como mi-pagina.vercel.app
  7. Regresa a Tecnosofia: Pega tu enlace y elige tu subdominio

📚 Guía: Subir tu página a Vercel

Sigue estos pasos sencillos. No necesitas saber programar.

  1. Ve a vercel.com y haz clic en "Sign Up". Puedes usar tu cuenta de GitHub, GitLab o crear una con email.
  2. Prepara tus archivos: Solo necesitas un archivo llamado index.html con tu contenido. Ejemplo básico: 
    <!DOCTYPE html>
<html><head><title>Mi Página</title></head>
<body><h1>¡Hola Mundo!</h1></body></html>
  3. Sube tu proyecto:
    • Opción A: Arrastra tu carpeta con el archivo en la página de Vercel
    • Opción B: Conecta tu cuenta de GitHub si tu código está allí
  4. ¡Listo! Vercel te dará un enlace como mi-proyecto.vercel.app. Cópialo y regresa a Tecnosofia para continuar.
